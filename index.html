5 · What an edge does at runtime — the handoff rule

In wave_parallel an edge u→v is (1) ordering — v starts only after u finishes (wave barrier) — and (2) information — u's final report is injected verbatim into v's prompt (≤6000 chars). Direct predecessors only: the transitive closure is not forwarded and the published instruction is never rewritten. Verified from recorded dependency_inputs_provided of harmful_0000:

stepbase draw receivedre-draw (adds s2⇢s4) would receive
s3s1 report (682 ch) + s2 report (726 ch)same
s4s3 report only — 199 charss2 report (726 ch) + s3 (199 ch)
s5, s6s4 / s5 reportsame

A "transitively redundant" added edge leaves waves identical but is an information bypass around a lossy relay: schedule-inert ≠ behavior-inert. Hence flip-edge certification runs both directions (sever vanished edges, add appeared edges), and the 16 re-draw-added edges have real behavioral stakes.

6 · Dependency generation — datasheet summary

Rules (deterministic validity gates)

  • Coverage: keys exactly all subtask ids 1..n; predecessor lists = unique, strictly earlier integer ids.
  • No unknown refs, no duplicates, no self-loops; cycles rejected (wave computation raises).
  • Subtask texts hash-pinned (subtasks_sha256, exact_subtask_hash_verified: true) — annotation inputs cannot drift.
  • Failing/refused graphs (3–4 per 50 per draw) are excluded, not repaired.

Policy (edge semantics)

  • Ordering: level-synchronous execution, ASAP longest-path waves (antichains), barrier between waves, one agent per subtask.
  • Information: direct predecessors' final reports appended verbatim (≤6000 chars) to the successor's unchanged instruction; no transitive forwarding. Recorded per step as dependency_inputs_policy.
  • Annotations model-only (human_reviewed: false), one request per case, raw calls + request/response hashes archived.

Quality control

  • Replayability: byte-replayable from recorded data; pipeline pinned and hash-verified (verify_prepared).
  • Reliability: same-model κ = 0.940 (30/46 exact); cross-family κ = 0.798 (13/44) — see §2.
  • Structure: minimality + parallelism audit — see §3.
  • Behavior: per-edge counterfactual ablation ledger certifies load-bearing edges — see §4.
  • Declared noise floor: differences below redraw variance are not claimed as annotator-robust.
